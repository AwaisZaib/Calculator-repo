# Python Scientific Calculator

A command-line scientific calculator built using Python. This project performs basic arithmetic operations, scientific calculations, trigonometric functions, inverse trigonometric functions, and number-system conversions.

# Features

### Basic Arithmetic
- Addition
- Subtraction
- Multiplication
- Division
- Power
- Percentage

### Scientific Operations
- Square root
- Logarithm (base 10)
- Factorial

### Trigonometric Functions
- Sin
- Cos
- Tan

### Inverse Trigonometric Functions
- Inverse Sin (asin)
- Inverse Cos (acos)
- Inverse Tan (atan)

### Number System Conversions
- Decimal to Binary
- Decimal to Octal
- Decimal to Hexadecimal

# Error Handling
- Handles division by zero using `ZeroDivisionError`
- Validates the input range for inverse trigonometric functions

# Technologies Used

- Python
- `math` module
- Git
- GitHub
